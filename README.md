# Login Page

A simple, responsive login page built with HTML, CSS, and vanilla JavaScript.

## Features

- Email and password fields with basic client-side validation
- Show/hide password control
- Remember me checkbox
- Inline validation and status messages
- Responsive, centered login card

## Run locally

Open `demo.html` in a web browser. No build tools or dependencies are required.

## Project files

- `demo.html` — login page markup
- `demo.css` — page styling
- `demo.js` — password visibility and client-side form behavior

> **Note:** This is a front-end demonstration. It does not authenticate users or connect to a server. A real login requires a secure backend and should never rely on client-side validation alone.
