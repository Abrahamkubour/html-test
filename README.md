# Login Page

A simple login page built with HTML, CSS, and vanilla JavaScript.

## Features

- Email and password fields
- Basic client-side input validation
- Show/hide password control
- Remember me checkbox
- Inline status and validation messages
- Responsive layout

## Run locally

Open `demo.html` in a web browser. No installation or build tools are needed.

## Project files

- `demo.html` — page structure
- `demo.css` — styling
- `demo.js` — password visibility and form validation

## Note

This is a front-end demonstration. It does not authenticate users or connect to a server. Real authentication requires a secure backend; client-side validation alone is not sufficient.
